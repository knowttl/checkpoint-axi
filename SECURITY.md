# Security

Report suspected vulnerabilities privately to the maintainers through [GitHub security advisories](https://github.com/knowttl/checkpoint-axi/security/advisories/new).
If private reporting is unavailable, contact a maintainer through the [repository owner profile](https://github.com/knowttl) to arrange a private channel before sharing details.
Do not put vulnerability details, credentials, tokens, tenant responses or customer identifiers in public issues or pull requests.

Include the affected package version, a description of the impact and reproduction steps using synthetic data.
Use `checkpoint-axi --version` to identify the installed version.
For operational safety, review [write gates](docs/writes.md), [private downloads](docs/downloads.md) and [credential handling](docs/configuration.md).
